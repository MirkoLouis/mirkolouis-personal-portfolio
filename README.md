# Personal Portfolio Website - MW2 'The Haunting' Theme

This is a personal portfolio website built with Node.js, Express, HBS, and Bootstrap 5. The theme is inspired by the MW2 'The Haunting' event, featuring a crossover with Diablo 4's Lilith.

## Technologies

- **Backend:** Node.js, Express
- **Frontend:** HBS (Handlebars), Bootstrap 5, CSS3
- **Deployment:** The application can be deployed to any service that supports Node.js.

## Features

- **Themed UI:** A high-tech military UI blended with a dark, supernatural aesthetic.
- **Custom Animations:**
    - **Corruption Glitch:** A chromatic aberration effect on hover states.
    - **CRT Scan Lines:** An overlay to mimic a CRT screen.
    - **Pulse Animation:** A pulsing effect for the "Status: DEPLOYED" text.
    - **Radar Sweep:** An animated radar for the contact section.
- **Responsive Design:** The layout is fully responsive, thanks to Bootstrap 5.

## How to Install and Run

1.  Clone the repository:
    ```bash
    git clone <repository-url>
    ```
2.  Navigate to the project directory:
    ```bash
    cd <project-directory>
    ```
3.  Install the dependencies:
    ```bash
    npm install
    ```
4.  Start the application in development mode (with auto-restarting):
    ```bash
    npm run dev
    ```
    This uses `nodemon` to automatically restart the server when you make changes to project files.

5.  Or, start the application in production mode:
    ```bash
    npm start
    ```

6.  Open your browser and navigate to `http://localhost:3000`.
